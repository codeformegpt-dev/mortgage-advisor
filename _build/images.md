# מקומות התמונות: איזה קובץ להעלות לאן

כל מקום של תמונה בשתי הגרסאות מחפש קובץ בשם קבוע בתיקייה `assets/img/`. מעלים קובץ בשם הזה (למשל דרך GitHub, Add file ← Upload files), והתמונה מופיעה לבד, בלי לשנות קוד. עד אז המקום נשאר מעוצב וריק, ו"תמונה להמחשה" מוסתר (אין מה לסמן). כשהתמונה נטענת, "תמונה להמחשה" מופיע אוטומטית.
